=== CONTROLS ===

This is a document explaining the controls of the game!
These can all be re-binded, but these are all of the defaults.
Below will be some layouts that I made and reccommend if you don't like the
default!

Formatting notice: Directions (e.g., [UP]) notate the arrow keys that are for
that direction. Also, keys like alt, shift, and ctrl will be notated as side
(L/R) + the name in all caps (example: left ctrl = LCTRL).


=== Default ===

Menu Navigation:
- Menu Up      : [UP]
- Menu Down    : [DOWN]
- Menu Left    : [LEFT]
- Menu Right   : [RIGHT]
- Menu Decrease: [LEFT]
- Menu Increase: [RIGHT]
- Menu Exit    : [X]
- Select       : [RETURN]

Gameplay (1D & 2D Modes):
- Game Move Left : [A]
- Game Move Right: [D]
- Game Pause     : [ESCAPE]
- Game Dash      : [E]

Gameplay (1D Mode):
- Game Jump (1D)     : [W]
- Game Slow/Land (1D): [S]

Gameplay (2D Mode):
- Game Move Up (2D)  : [W]
- Game Move Down (2D): [S]
- Game Jump (2D)     : [UP]
- Game Slow/Land (2D): [DOWN]

Other:
- Screenshot: [F2]
