* Changes so Far
If you're coming here for gameplay updates, note that this is a mix of both
technical changes and updates!
- Save file is now in JSON
- Save file can now be generated if not found
  - This also means that the save file does not need to be packaged/included!
- Various excsessive comments removed
- Various variables renamed (to make more sense, fit conventions, etc.)
- Colour palette changing added. This means:
  - New colour palette option in settings, reloads images when changed
  - Colour palette is applied when loading images
  - Assets reload now rebuilds other magic variables
  - Colour palette preview in options menu
  - Some magic variable architecture changed to accomodate
- wintop.py moved into mod/etc
- Other minor changes, including but not limited to:
  - Corrected links in terminal greeting
- Added optional mouse-based player movement
  - This is done by simply adding mouse input to the normal movement system
- Got rid of updates screen, how to play screen, and about screen. They're
  excsessively (did I spell that right?) complictaed for an arcade game, and
  web pages/TXT files do that better for various reasons (update no. 3 in
  updates.yaml, read it).
  - Add license stage to disclose basic licensing info.
- Added falling scorers.
  - Added the constants for falling scorers
  - Added the assets for falling scorers (images, sfx)
  - Added the scoring functions for falling scorers
  - Slightly changed falling object type picking logic to allow scorers to exist
  - /The chances will need to be iterated on and tweaked!/
- Added constants override
  - This will be needing documentation.
  - Added the -c flag for constants override.
  - Added the empty (for now) JSON file for constants override.
  - Added the constants override logic to the game constants module.
- Various refactors, many involving breaking mega-functions into multiple
  smaller functions.
- Added "notifs" (I couldn't think of a better name) that appear when you:
  - Get points
  - Collide with a heal/enemy/falling object
  ...as small numbers/symbols over you.
- Added keybindings menu as an argument in the options func (and its own stage
  for ease of use)
- Added helper function in save module for getting key input
- Added "No music" soundtrack
  - This required adding the ability for the music module to stop music if the
    track is None
- Removed "Alternate" soundtrack
